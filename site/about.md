## A small app with an overengineered scope

This is a TodoMVC-style application I wrote to teach myself functional
programming. Its functionality is deliberately modest: you can keep track of
tasks, mark them complete, and experience the rare pleasure of an empty list.

The todos are not really the point. The project is a place to learn how to
build better software. As such, it is deliberately engineered on a larger
scale than a basic todo app requires. The intent is that you can replace the
todo functionality with your own custom app while keeping the underlying
structure.

This is not a productivity platform, a collaboration suite, or an AI-powered
synergy engine. It is a small application built carefully, one function at a time.
